# 🔥 «Нет тепла? Сообщите!» — Telegram-бот для г.о. Черноголовка

Бот собирает обращения жителей Черноголовки об отсутствии отопления и горячей воды,
сохраняет их в базу, сразу пересылает администраторам и (по желанию) дописывает в Google Таблицу.

## Что спрашивает бот
1. Тип проблемы (нет отопления / батареи еле тёплые / нет горячей воды / холодно в подъезде / другое)
2. Адрес — улица и дом (и населённый пункт, если не Черноголовка)
3. Квартира (можно пропустить)
4. Как давно нет тепла
5. Телефон — кнопкой «Отправить мой номер» (можно пропустить)
6. Комментарий (можно пропустить)
7. Подтверждение → заявке присваивается номер

## Команды
| Команда | Кто | Что делает |
|---|---|---|
| `/start` | все | приветствие со слоганом |
| `/report` | все | оставить заявку |
| `/cancel` | все | отменить заполнение |
| `/stats` | админы | сводка: всего, за сегодня, по адресам и типам |
| `/export` | админы | выгрузка всех заявок в CSV (открывается в Excel) |

## Запуск
1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`), получите токен.
   Описание со слоганом и меню команд бот заполнит сам при первом запуске
   (если они уже заданы в @BotFather — не тронет).
   Аватарка — файл `avatar.jpg` (в @BotFather: `/setuserpic`).
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Установите и запустите:
   ```bash
   cd heat_bot
   python3 -m venv venv && . venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env   # впишите BOT_TOKEN и ADMIN_IDS
   python bot.py
   ```
4. Чтобы заявки приходили в общую группу — добавьте бота в группу и укажите её ID в `ADMIN_CHAT_ID`.

Заявки хранятся в SQLite-файле `reports.db`.

## Запуск на сервере (постоянно)
Подойдёт самый дешёвый VPS с Ubuntu 22.04 или 24.04, но **за пределами России** (Нидерланды,
Германия, Финляндия): с российских серверов доступ к Telegram API с 2026 года блокируется.
Подключитесь к нему по SSH под root и выполните, подставив свои значения в `.env`:
```bash
apt update && apt install -y git
git clone -b claude/quirky-brown-oqk90v https://github.com/sikmaoleg/testProg.git /opt/testProg
cat > /opt/testProg/heat_bot/.env <<'EOF'
BOT_TOKEN=123456789:AAAA-your-token
ADMIN_IDS=111111111
GOOGLE_SCRIPT_URL=
EOF
bash /opt/testProg/heat_bot/deploy/install.sh
```
Скрипт `deploy/install.sh` ставит зависимости и регистрирует бота службой systemd `heat-bot`:
она запускается при включении сервера и перезапускает бота после сбоя.
- Состояние: `systemctl status heat-bot`, журнал: `journalctl -u heat-bot -f`.
- Обновить бота: `cd /opt/testProg && git pull && bash heat_bot/deploy/install.sh`.
- С одним токеном может работать только одна копия бота — другие остановите.
- Номера заявок ведёт база `reports.db`. Если база начата заново (например, на новом сервере),
  удалите из Google Таблицы старые строки — иначе новые заявки с теми же номерами туда не попадут.

## Google Таблица (по желанию)
Бот может дописывать каждую заявку строкой в Google Таблицу.

1. Создайте таблицу на [sheets.google.com](https://sheets.google.com).
2. В таблице откройте **Расширения → Apps Script**, удалите всё в редакторе, вставьте код
   из файла [`google_script.gs`](google_script.gs) и сохраните (💾).
3. **Начать развертывание → Новое развертывание**, тип — **Веб-приложение**:
   «Выполнять как» — **Я**, «У кого есть доступ» — **Все**. Нажмите «Начать развертывание»
   и разрешите доступ (если Google предупредит, что приложение не проверено:
   «Дополнительные настройки» → «Перейти на страницу…»).
4. Скопируйте **URL веб-приложения** (оканчивается на `/exec`) в `.env`:
   `GOOGLE_SCRIPT_URL=https://script.google.com/macros/s/…/exec` — и перезапустите бота.

При запуске бот допишет в лист «Заявки» все уже собранные заявки, дальше — каждую новую.
- Таблицу можно редактировать: сортировать, удалять строки, добавлять свои столбцы справа
  (например, «Статус»). Не трогайте только первый столбец «№» — по нему бот избегает дублей.
- Ссылку на веб-приложение никому не показывайте: по ней можно дописывать строки в таблицу.
- Если запись не удалась, бот напишет администраторам и повторит со следующей заявкой.

# Звёздная Империя (StarEmpire)

Космическая игра для Roblox: станция, 6 секторов с уникальными локациями, добыча руды, бои с дронами, босс, улучшения корабля, ежедневные задания и монетизация (кредиты, пропуски, донат-титулы, история покупок).

## Что внутри

**Игровой цикл**
- **Станция «Орбита-1»** — торговый терминал (продажа руды), порталы в сектора, меню «Командный центр» (клавиша **M**).
- **6 секторов** (открываются по уровню): Луна → Марс → Пояс астероидов → Европа → Кольца Сатурна → Туманность Ориона. У каждого свой цвет неба, рельеф, планета-фон, руда и враги.
- **Добыча**: зажмите E у светящихся руд; трюм ограничен, а при гибели груз теряется.
- **Бой**: ЛКМ стреляет лазером; дроны преследуют игрока. В Туманности Ориона — босс «Чёрный Левиафан», возрождается через 5 минут.
- **Прогрессия**: опыт за добычу, убийства и задания → уровень → новые сектора. Улучшения: лазер, бур, трюм.
- **Ежедневные задания** (сбрасываются каждые 24 часа) и ежедневная награда.
- **Таблица лидеров**: Уровень и Кредиты.

**Монетизация** (вкладка «Донат» и «История» в меню)
| Что | Тип | Цена (R$) | Эффект |
|---|---|---|---|
| Пакеты «Старт / Капитан / Адмирал» | Developer Product | 25 / 99 / 399 | 5 000 / 25 000 / 120 000 кредитов |
| Поддержать автора / Меценат / Легенда | Developer Product | 99 / 299 / 999 | Титулы Supporter / Patron / Legend (видны над головой) |
| Экстренный ремонт | Developer Product | 15 | Полное лечение в бою |
| VIP-пилот | Gamepass | 199 | ×2 кредитов, золотой лазер, титул VIP |
| Расширенный трюм | Gamepass | 99 | +50 к трюму |
| Турбо-двигатели | Gamepass | 79 | Скорость +30% |

- Все покупки записываются в **историю покупок** (дата, товар, сумма) и в счётчик «Всего на поддержку».
- Robux-покупки обрабатываются через `MarketplaceService:ProcessReceipt` с защитой от двойного начисления (номера чеков сохраняются в профиле).
- Платного рандома (лутбоксов) в игре нет — это важно для правил Roblox.

## Структура

```
roblox/
├── default.project.json           # конфиг Rojo
└── src/
    ├── shared/                    # → ReplicatedStorage.Shared
    │   ├── Config.luau            # баланс, секторы, товары, тексты
    │   └── Remotes.luau           # удалённые события между клиентом и сервером
    ├── server/                    # → ServerScriptService
    │   ├── Main.server.luau       # точка входа: запуск сервисов, игроки, автосохранение
    │   ├── DataService.luau       # профили в DataStore, кредиты, опыт, титулы, история
    │   ├── MonetizationService.luau  # Robux: пропуски, товары, чеки
    │   ├── ShopService.luau       # обработка кнопок меню и профиль для интерфейса
    │   ├── QuestService.luau      # задания и ежедневная награда
    │   ├── WorldBuilder.luau      # станция, сектора, порталы (карта строится кодом)
    │   ├── MiningService.luau     # руда, трюм, торговый терминал
    │   └── CombatService.luau     # лазер, ИИ дронов и босса, награды
    └── client/                    # → StarterPlayerScripts
        ├── Client.client.luau     # точка входа клиента, выстрелы
        ├── UI.luau                # HUD, уведомления, командный центр с вкладками
        └── Effects.luau           # звёздное небо и цвет освещения по секторам
```

## Запуск

1. Установите [Rojo](https://rojo.space) (через Aftman или Foreman) и плагин Rojo в Roblox Studio.
2. В папке `roblox/` выполните `rojo serve`.
3. В Studio откройте пустой Baseplate и нажмите **Connect** в плагине Rojo.
4. Нажмите **Play**.

Без Rojo игра не соберётся: структура файлов намеренно разложена по папкам, как в Rojo-проекте.

## Перед публикацией (обязательно)

1. **Game Settings → Security → Enable Studio Access to API Services**, иначе DataStore не работает (в Studio игра покажет предупреждение, но продолжит работать без сохранений).
2. **Creator Hub → Monetization**: создайте 3 геймпасса и 7 товаров из таблицы выше. Укажите цены в R$ точно такими, как в `Config.luau` (поля `robux`).
3. Вставьте полученные ID в `src/shared/Config.luau` вместо `id = 0` (у `GamePasses` и `DevProducts`). Пока ID равен 0, кнопка покупки покажет «ещё не добавлен в игру».
4. Включите **Game Settings → Monetization → Enable Developer Product purchases**, иначе ProcessReceipt не сработает.
5. Проверьте все покупки в Studio через тестовые аккаунты до публикации.

## Что ещё не проверено

- Код написан без запуска в Roblox Studio, поэтому перед релизом обязательно пройдите игру в Play-режиме: возрождение, батуты-порталы, ИИ дронов (поведение `Humanoid` без конечностей), покупки.
- Значения баланса (урон, цены, награды) — стартовые, их стоит подобрать по тестам.

## Идеи для развития

- Корабли и скины (косметика за кредиты или Robux).
- Кооператив: группы на рейд босса.
- Сезонный боевой пропуск (battle pass) с наградами по уровням.
- Процедурные события: метеоритные дожди, пиратские налёты.
- Рейтинги за неделю и перенос статистики между сезонами.
